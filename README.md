# Assignment 6 - jQuery

## Description
This project is about jQuery selectors, effects, DOM manipulation, and animations.

## Technologies
- HTML
- CSS
- JavaScript
- jQuery

## Tasks
- Task 0–1: Setup and Selectors
- Task 2–4: Effects
- Task 5–7: DOM Manipulation
- Task 8–10: Animations
- Task 11: Accordion Menu

## How to Run
1. Download the project.
2. Open `index.html` in your browser.
3. Use the navigation bar to switch between tasks.

Internet connection is required for the jQuery CDN.
